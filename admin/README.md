# 题库管理后台（Streamlit）

`admin/` 是独立的管理后台，直接连接后端业务数据库，不修改 `backend/` 与 `frontend/` 中的任何文件。

## 启动方式

在项目根目录（含 `backend/`、`frontend/`、`admin/` 的目录）下执行：

```bash
# 1. 安装依赖
python -m venv .venv-admin
source .venv-admin/bin/activate        # Windows: .\.venv-admin\Scripts\Activate.ps1
pip install -r admin/requirements.txt

# 2. 如果尚未建表 / 没有种子数据，先执行一次种子脚本（在 backend 目录）
cd backend
python seed.py
# 或直接启动后端，由后端自动建表：python main.py

# 3. 回到项目根目录启动管理后台
cd ..
streamlit run admin/app.py
```

浏览器默认打开 `http://localhost:8501`。

管理后台**不会自动建表**。如果数据库文件或表不存在，页面会提示先启动后端或执行种子脚本。

## 数据库连接

默认使用 SQLite：

```text
<项目根目录>/backend/data/app.db
```

程序基于 `admin/app.py` 所在目录向上定位项目根目录，不写死 Windows 绝对路径。实际连接地址显示在左侧边栏（已隐藏密码）。

可通过环境变量覆盖（`DATABASE_URL` 优先）：

```powershell
# SQLite（相对/绝对路径均可）
$env:DATABASE_URL = "sqlite:///C:/path/to/app.db"

# MySQL
$env:DATABASE_URL = "mysql+pymysql://root:password@127.0.0.1:3306/question_bank?charset=utf8mb4"

streamlit run admin/app.py
```

也支持项目根目录或 `admin/` 目录下的 `.env` 文件，例如：

```dotenv
DATABASE_URL=mysql+pymysql://root:password@127.0.0.1:3306/question_bank?charset=utf8mb4
ADMIN_USER=admin
ADMIN_PASSWORD=请改成强密码
```

注意：管理后台使用的表结构由后端 `backend/app/models.py` 决定，请保持前后端连接同一个数据库。

## 默认管理员

| 项目 | 默认值 | 覆盖方式 |
| --- | --- | --- |
| 账号 | `admin` | 环境变量 `ADMIN_USER` |
| 密码 | `admin123` | 环境变量 `ADMIN_PASSWORD` |

首次部署后请立即通过环境变量修改默认密码。管理后台登录状态保存在浏览器会话中，侧边栏可退出登录。

## 功能说明

### 数据概览

- 注册用户数、已发布题目数、答题记录数、有效会员数、考试数。
- 按章节统计答题数、正确数与正确率（包含练习和考试模式）。
- 正确率 = 正确答题记录数 / 答题记录总数。

### 题目管理

- **Excel 批量导入**：上传 `.xlsx`，预览前 50 行，逐行校验，错误行会标出 Excel 行号与原因；校验全部通过后才允许确认导入。
- **单题编辑**：按题目 ID 加载，可修改省份、章节、题型、题干、A~F 选项、答案、解析、难度、年份、来源说明、关联条文 ID、是否免费、状态。
- **发布与下架**：批量填写题目 ID，把状态改为 `published` 或 `draft`。
- **题目列表**：按省份、状态、题型、题干关键词筛选，最多显示 1000 条。
- 新导入题目默认 `status=published`，`created_at` 取导入时间。
- 选项统一写为 `[{"key":"A","text":"..."}]`，答案统一写为 `["A"]`，与后端序列化格式一致。

### 法规管理

- **Excel / CSV 按条导入**：同一「省份 + 法规名称」视为同一法规文档；文档不存在时自动创建，存在时直接追加条文。
- `sort_order` 在该文档现有最大值基础上递增。
- 默认跳过「同文档 + 同条号」的重复条文，可在导入前取消勾选。
- **法规列表**：查看文档、分类、发布日期、效力状态、条文数；按省份/分类/状态/名称筛选。
- 可修改法规文档的效力状态（现行有效 / 已修订 / 已废止）；不提供删除，下架请改状态。

### 激活码

- 批量生成：数量 1~500、有效天数、可选前缀与备注。
- 激活码字符集为大写字母 + 数字，排除了易混淆的 `I/O/0/1`，随机主体长度为 12。
- 生成结果可下载 CSV（UTF-8 BOM，Excel 直接打开不乱码）。
- 列表支持状态筛选与关键词搜索，可查看使用者手机号、昵称与使用时间。
- 可禁用所选激活码；仅「已禁用且从未被使用」的激活码可恢复为未使用。
- 已使用激活码被禁用不会影响已经开通的会员。

### 用户管理

- 用户列表：ID、手机号、昵称、省份、角色、注册时间、会员到期时间、会员状态。
- 查看用户做题数、正确数、正确率、错题数、考试数。
- 按手机号开通/延长会员：未过期则在原到期时间上累加，已过期或未开通则从当前时间起算。
- 重置密码：使用 passlib bcrypt（与后端一致）。管理后台依赖未包含 passlib，需要额外安装：
  ```powershell
  pip install "passlib[bcrypt]"
  ```
  未安装时页面会提示，且不会修改密码。

### 配置管理

- **考试参数**：按省份编辑并 upsert `exam_configs` 的 `question_count`、`duration_minutes`、`pass_score`、`total_score`、`type_distribution`。
- `type_distribution` 使用 JSON 文本，例如：
  ```json
  {"single": 10, "multi": 4, "judge": 6}
  ```
- 页面明确提示：**[待定] 数值由管理员填写，系统不预置正式值**。
- 留空的字段不会写入数据库，也不会覆盖已有值。
- **站点配置**：编辑 `service_phone`、`service_wechat`、`service_intro`，并支持新增任意自定义键（小写字母、数字、下划线）。
- 保存站点配置时，空值也会写入空字符串，便于清空原有内容。

### 意见反馈

- 按时间倒序展示反馈内容、用户手机号/昵称、提交时间，支持关键词过滤。

## 题目 Excel 列约定

必须使用 `.xlsx`，第一行为表头。列名严格按以下顺序与写法（顺序可调整，名称不能改）：

| 列名 | 必填表头 | 说明 |
| --- | --- | --- |
| 省份 | 是 | 中文省份名、简称或代码，如 `四川省`、`四川`、`SC`；全国通用填 `national` 或 `全国通用` |
| 章节 | 是 | 按「省份 + 章节名」匹配 `chapters`；同名多章节时填「父章节/子章节」路径或章节 ID |
| 题型 | 是 | 只能是 `single`（单选）、`multi`（多选）、`judge`（判断） |
| 题干 | 是 | 题目正文 |
| 选项A ~ 选项F | 选项A 必填表头 | 选项内容，可留空；判断题六个选项全空时自动生成 A 正确 / B 错误 |
| 答案 | 是 | 单选 `A`；多选 `A,B`、`AB`、`A、B`；判断 `A` / `B` 或 `正确` / `错误` |
| 解析 | 否 | 答案解析 |
| 难度 | 否 | `easy` / `medium` / `hard`，也接受 简单 / 中等 / 困难；留空为 `medium` |
| 真题年份 | 否 | 4 位数字，例如 `2024`；留空表示非真题 |
| 来源说明 | 否 | 题目来源备注 |
| 关联条文 | 否 | 法规条文 ID，可填 `12,15` 或 JSON 数组 `[12,15]` |
| 是否免费 | 是 | 是/否、TRUE/FALSE、1/0 均可 |

答案校验规则：

- 答案中的字母必须存在于已填写的选项中。
- 单选题必须恰好一个答案；多选题至少两个答案；判断题恰好一个答案。
- 答案也可直接填写选项文本（会匹配到对应选项）。
- 判断题选项留空时自动生成两个选项：`A=正确`、`B=错误`。

示例行（可在 Excel 中直接照此填写）：

| 省份 | 章节 | 题型 | 题干 | 选项A | 选项B | 选项C | 选项D | 选项E | 选项F | 答案 | 解析 | 难度 | 真题年份 | 来源说明 | 关联条文 | 是否免费 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 四川省 | 第一章 政府采购基础/第一节 基本概念 | single | 政府采购的主体不包括？ | 采购人 | 供应商 | 财政部门 | 银行 |  |  | D | 示例解析 | easy | 2024 | 管理员导入 | 12,15 | 是 |
| national | 章节名 | judge | 示例判断题 |  |  |  |  |  |  | 正确 | 示例解析 | medium |  | 管理员导入 |  | 否 |

页面提供「下载题目导入模板」按钮，模板只包含表头，避免误导入示例数据。

## 法规 Excel / CSV 列约定

支持 `.xlsx` 与 `.csv`（UTF-8 / GBK 自动尝试）。第一行为表头：

| 列名 | 必填表头 | 说明 |
| --- | --- | --- |
| 省份 | 是 | 中文省份名、简称或代码；全国性法规填 `national` 或 `全国通用` |
| 法规名称 | 是 | 同一「省份 + 法规名称」归为同一文档 |
| 分类 | 是 | 只能是 `国家法律`、`行政法规`、`部门规章`、`地方规定` |
| 发文单位 | 否 | 发文机关 |
| 发布日期 | 否 | `YYYY-MM-DD`、`YYYY/MM/DD`、`YYYY.MM.DD`、`YYYY年MM月DD日` 等 |
| 修订日期 | 否 | 同上 |
| 效力状态 | 否 | 现行有效 / 已废止 / 已修订，或 `effective` / `repealed` / `revised`；留空为现行有效 |
| 条号 | 是 | 例如 `第一条`、`1` |
| 条文内容 | 是 | 条文正文 |

导入说明：

- 同一文件内、同一「省份 + 法规名称」只创建一次文档，文档元数据取该组第一行。
- 如果数据库中已存在同名同省份文档，不会覆盖其分类、发文单位、日期、状态，只追加条文。
- 默认跳过已存在的「同文档 + 同条号」；取消勾选后会插入重复条号。
- 页面提供 Excel 与 CSV 两种模板下载。

## 注意事项

- 管理后台直接读写业务数据库，没有二次确认与回收站；执行批量操作前请备份数据库。
- 题目和法规导入均为「全部校验通过才写入」，任意一行错误都会阻止整批导入。
- 管理后台不提供删除用户、题目、法规、激活码的功能，避免误删关联数据。
- 激活码恢复只适用于「已禁用且从未被使用」的记录；已使用记录保留使用历史。
- 修改 `exam_configs` 后，后端考试配置接口会立即读取新值；`type_distribution` 必须是合法 JSON 对象。
- 考试参数中的数值目前没有正式值，页面中的 `[待定]` 提示表示必须由管理员确认后填写。
- 如果运行中由后端新增了表或修改了表结构，点击侧边栏「刷新表结构 / 数据」重新反射。
- MySQL 连接需保证账号有对应库的读写权限；SQLite 默认文件位于 `backend/data/app.db`。
