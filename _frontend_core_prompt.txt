### 8. frontend/src/api/client.js
axios 实例：baseURL "/api"，timeout 15000；请求拦截器附带 `Authorization: Bearer <localStorage sx_token>`；响应拦截器：401 时清除 token 并派发 window 事件 `auth:unauthorized`，错误统一抛出（error.response?.data?.detail 作为 message 挂在 error 上）。导出 `http`。

### 9. frontend/src/api/*.js（按域拆分，导出命名函数）
- auth.js：register({phone,password,nickname})、login({phone,password})、getMe()、updateSettings(payload)
- chapters.js：getProvinces()、getChapters(provinceCode)
- questions.js：getQuestions(params)（chapter_id/mode/year_only/province_code）、submitAnswer(id, selected)、getStats()、getSiteConfig()、sendFeedback(content)
- wrong.js：getWrong()、removeWrong(questionId)
- favorites.js：getFavorites(targetType)、addFavorite(targetType, targetId)、removeFavorite(targetType, targetId)
- laws.js：getLaws(params)、getLaw(id)、searchLaws(q, provinceCode)
- exams.js：getExamConfig(provinceCode)、startExam(payload)、getExam(id)、saveExamAnswer(id, questionId, selected)、submitExam(id, answers)、getExamResult(id)、getExamHistory()
- members.js：activate(code)

所有函数返回 `res.data`。

### 10. frontend/src/stores/auth.js（Pinia setup 或 options 均可）
state：`token`（localStorage "sx_token"）、`user`、`ready`。
getters：`isLoggedIn`、`isMember`（role==="admin" 或 membership_expires_at 晚于当前时间）、`nickname`、`phone`。
actions：
- `bootstrap()`：若 token 存在则 getMe，更新 user；失败 logout；最后 ready=true。无 token 直接 ready=true。
- `login(payload)` / `register(payload)`：调接口，保存 token 与 user。
- `logout()`：清 token、user。
- `refreshMe()`。
- `updateSettings(payload)`：调接口并更新 user（合并 settings）。
- 监听 window 的 `auth:unauthorized` 事件自动 logout（在 store 初始化时绑定一次即可）。
同时暴露 `isMember` 的辅助函数（例如导出 `isMembershipActive(user)`），供非 setup 场景使用。

### 11. frontend/src/stores/ui.js
state：`theme`（"light"|"dark"）、`fontSize`（"small"|"medium"|"large"）、`provinceCode`（游客本地省份，localStorage "sx_province"）、`provinces`（缓存）。
actions：
- `applyToDocument()`：设置 `document.documentElement.dataset.theme / dataset.font` 与 meta theme-color。
- `setTheme` / `toggleTheme` / `setFontSize`；持久化到 localStorage（sx_theme / sx_font）。
- `setProvinceCode(code)`：写 localStorage。
- `loadProvinces()`：调 getProvinces 并缓存。
- `init()`：读取 localStorage 并 applyToDocument。
注意：登录用户真实省份以 auth.user.province_code 为准，该 store 只负责游客本地值。

### 12. frontend/src/components/
- `TabBar.vue`：固定底部，4 个 tab（练习 /、考试 /exam、服务 /service、我的 /me），内联 SVG 图标（练习=书本、考试=试卷/时钟、服务=工具/对话、我的=人像），激活态主色，高度 ≥56px + safe-area，路由高亮用 `router-link-active` 或 path 判断。不要用 emoji。
- `TopBar.vue`：props `title`、`back`（默认 true）、`rightText`；高 ≥48px，顶部安全区 padding；返回按钮内联 SVG 箭头（router.back()），右侧文字按钮可选；emit("right")。
- `Skeleton.vue`：props `rows`（默认 3），渲染骨架卡片。
- `Empty.vue`：props `text`、`sub`，内联 SVG 空状态图标。
- `ProgressBar.vue`：props `value`（0-100），展示 `progress` 结构。
- `Modal.vue`：底部弹出式弹层（teleport to body），props `modelValue`、`title`；emit update:modelValue；默认插槽、footer 插槽；遮罩点击关闭；适配安全区。
- `Toast.vue` 或 `useToast`：简单全局提示。可创建 `src/composables/useToast.js`，导出响应式 message 与 showToast(text, type) 函数；App.vue 内渲染。
- `icons.js`：集中定义需要的 SVG path 字符串（书、卷、服务、用户、搜索、返回、收藏、勾、叉、电话、微信、箭头等），组件可复用。

### 15. frontend/public/sw.js
手写 service worker：
- install：skipWaiting；activate：clients.claim，清理旧缓存。
- fetch：只处理 GET、同源请求；`/api/` 请求不缓存（直接 fetch）；其余静态资源用 stale-while-revalidate（先返回缓存，同时后台更新）；导航请求失败时回退到缓存的 "/"。
- 明确注释：答案与解析不进入缓存（因为接口不返回答案，且 /api 不缓存）。
- 不缓存非 GET。
